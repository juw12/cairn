title: AI agents as brain members
type: idea
status: ready
tags: [agents, help-wanted]

---
Let AI agents join a brain like people do, with rules people can trust:

- **Labeled:** an agent badge on everything it touches, never passing as human
- **Scoped:** read the brain, write only to `proposals/`
- **Propose-only:** every change is a suggestion a human accepts or rejects
- **Accountable:** each agent has an owner and a short charter note

Works through an MCP server ([[mcp-server]]) so Claude, Copilot or Cursor can join without custom code.

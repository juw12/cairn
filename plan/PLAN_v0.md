# Cairn plan v0 (first draft, kept for the refine log)

**Idea:** a second-brain app for a GitHub repo. Notes live as Markdown in the repo.

## Features
- Notes editor with Markdown preview, `[[wikilinks]]`, backlinks, tags
- Kanban board for tasks
- Whiteboard canvas for brainstorming (drag cards, connect them)
- Graph view
- Full-text search
- GitHub sync (pull/push from the app)

## Stack
- Python local server + HTML/JS front-end
- Notes in `notes/` folder
